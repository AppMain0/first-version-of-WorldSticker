
# WorldSticker ⚽

Aplicación para gestionar figuritas del álbum del Mundial 2026.

## Funciones
- Cámara integrada
- Escaneo de figuritas
- Guardado visual
- Diseño simple y moderno

## Cómo iniciar

1. Instala Node.js
2. Instala Expo:
npm install -g expo-cli

3. Instala dependencias:
npm install

4. Ejecuta:
npm start
